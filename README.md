# SQL Data Analysis - Next Gen Software Hub

## 📌 Project Overview
This repository contains the SQL assignment for the Data Analytics Internship at Next Gen Software Hub Pvt. Ltd. It covers database creation, table setup, data insertion, and analytical queries using SQL.

---

## 🛠️ Tech Stack Used
- **Database Management System:** MySQL / SQL Server
- **Language:** Structured Query Language (SQL)

---

## 📊 SQL Key Concepts Covered
- Database & Table Creation (`CREATE DATABASE`, `CREATE TABLE`)
- Data Insertion (`INSERT INTO`)
- Filtering Data (`WHERE`, `IN`, `BETWEEN`, `LIKE`)
- Sorting Data (`ORDER BY ASC/DESC`)

---

## 📂 Repository Contents
- `Next_Gen_Software.sql` - Complete SQL script containing schema creation, sample data, and all analytical queries.
